# Rules:

1. AI must not implement new functionality. Its role is limited to assisting with existing code.
2. AI should primarily be used for porting the project to newer Minecraft versions.
3. When porting code, AI must preserve all existing functionality and behavior. Only make changes necessary for compatibility with the target version.
4. AI must not refactor, optimize, or restructure existing code unless explicitly requested.
5. After porting Java code, AI must also port the associated JSON files to ensure compatibility with the target version.
6. AI must not remove existing functionality or make unrelated changes.
7. AI must follow the project's existing coding conventions and architecture.
